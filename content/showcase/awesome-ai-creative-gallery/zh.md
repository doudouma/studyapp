## 图鉴本身

[Awesome AI Creative Gallery](https://li-xiu-qi.github.io/awesome-ai-creative-gallery/) 是 GitHub 用户 li-xiu-qi 维护的开源 AI 图像创作玩法图鉴，MIT 许可，零依赖静态站点——克隆仓库、打开 `index.html` 就能用。目前收录 49 个案例，分七个玩法分类——动态与表情 / 游戏与互动 / 图标与 SVG / 知识与表达 / 商业与设计 / 图片编辑 / 角色与故事——支持场景、玩法、模型三维筛选，中英双语切换加关键词搜索。

它自己的 README 立了一条阅读规则：先看效果，再找方法。每个案例都带原帖链接和参考提示词。

## 十个入门玩法（Datawhale 教程逐个拆）

教程把十个玩法分成五个场景组，每个都配了「怎么上手」和一条参考提示词；提示词均照录教程原文：

### 角色创作与动态资产

**1. 静态角色 → 微信动态表情包。** 把过去要在 AE、Live2D 里分层绑定或逐帧手绘的活儿，压成一条指令。先从「一个主体、一个动作」开始，镜头固定、动作结束回到起始姿势，重点看循环接头会不会跳、五官有没有变。

![循环动态表情包——角色眨眼挥手，结尾回到起始姿态](/showcase/aacg-play1-nod.gif)

```
基于上传的角色参考图，保持角色的发型、服装和背景特征不变。让角色完成一次眨眼并轻轻挥手，动作平稳自然，并在结尾完全回到初始姿态，生成首尾衔接的循环动图。
```

**2. 游戏角色成套动作素材。** 一张设定图拉出待机/行走序列，先验证画风与节奏再扩展其他动作，省掉手绘几天的等待；教程也提醒：导入引擎前还要人工对齐锚点和透明通道。

![像素风游戏角色待机与行走动作帧](/showcase/aacg-play2-pixel.jpg)

```
参考上传的角色原画，设计一组横版像素风角色的动作序列，分别展示待机和向右行走状态；严格保持角色服装配色、比例及像素密度一致，背景透明。
```

**3. 单张参考图 → 多角度设定板。** 解决「换个角度换张脸」的老毛病。先列出不许变的特征（发型、配饰、服装配色），生成后逐视图比对。

![多角度角色设定板——正/侧/背视图与表情特写](/showcase/aacg-play3-sheet.jpg)

```
参考上传的人物立绘，制作一张横向角色设定板，分别展示正面全身、侧面全身和背面视图，右侧补充两个不同情绪的面部特写；严格保持发型、服装版型、五官特征与配色一致，采用干净的单色背景。
```

### 电商广告与动态橱窗

**4. 一张商品图 → 四季海报与动态广告。** 两层进阶：先锁包装、标签和文字换背景，出成套静态物料；再加开盒、悬浮、旋转类微动效，进详情页和信息流。

![秋季背景置换的商品海报——包装与文字锁定](/showcase/aacg-play4-seasonal.jpg)

```
严格保留上传图片中的商品包装、瓶身形态、标签排版及文字不变；将背景置换为秋季木质桌面，侧光打下柔和暖调光线，点缀少量枫叶与干花，商品作为视觉绝对主体。
```

```
以商品图为基础，保持产品形态与表面标识完全一致；让包装盒盖平滑打开，主体产品缓慢升起并轻微悬浮，随后回归原位并闭合，生成平稳循环的展示动图，背景保持极简纯色。
```

### 原生矢量 SVG 与图标设计

**5. 批量可编辑 SVG 图标。** 直接产出矢量代码而不是位图，线条颜色交给 CSS 控制。统一描边粗细、圆角与强调色，先小批量试风格；官方说明原生 SVG 走独立接口，多图标画板上线前要拆成独立组件。

![线性天气图标集，输出为 SVG](/showcase/aacg-play5-weather-icons.png)

```
为天气应用设计一套线性图标，包含晴天、多云、小雨、大雪、雷阵雨、大风六个元素；统一采用 2px 描边、圆滑拐角与极简现代风格，统一强调色，输出格式为干净的 SVG 代码。
```

### 精准圈选与草图渲染

**6. 红圈局部修改。** 圈出目标，写明圈内改什么、圈外留什么，并要求清除标记；拿到结果先查交界边缘。

![红圈局部修改——外套改色，圈外全部锁定](/showcase/aacg-play6-revision.jpg)

```
将红圈标记区域的外套修改为深蓝色羊毛质感；除圈选区域外，严格锁定人物面容、发型、肢体姿势及背景环境不变；生成结果中移除标记红圈，交界边缘融合自然。
```

**7. 手绘草图 → 高保真渲染。** 草图不必精细，主体位置和透视画清楚就够；材质、光影、植被交给模型补，适合前期向客户交付概念方案。

![作为输入的手绘山谷线稿](/showcase/aacg-play7-sketch.webp)

![线稿渲染成的清晨写实山谷](/showcase/aacg-play7-valley.webp)

```
参考上传的手绘线稿，严格保留画面原有的构图、透视与主体位置关系；将草图渲染为清晨柔和侧光下的写实自然山谷，补充逼真的岩石肌理、地表植被与平静水面的反光细节。
```

### 界面原型与知识图解

**8. 手机应用与网页原型。** 产出的是视觉参考图不是代码；社区的做法是把效果图连同交互需求交给 Codex 这类编程智能体，打通创意到前端代码的链路。

![农夫市集移动端应用首页效果图](/showcase/aacg-play8-ui.webp)

```
为本地农夫市集设计一张移动端应用首页，包含商户列表、今日特惠及营业时间板块；采用白色极简背景与自然绿强调色，信息层级清晰分明，放置在手机屏幕框架内展示。
```

**9. 知识图解与图内文字翻译。** 能生成带箭头标注的原理图，也能保版式替换图内文字——教程最看好的是后者：海外技术图本地化不再抠图重排；医学、工程等严谨领域的术语仍要人工核验。

![细胞呼吸知识图解](/showcase/aacg-play9-respiration.webp)

```
将图片中的英文文字翻译为中文，替换对应位置的文本；保持原有的背景颜色、插图结构、引出箭头与整体排版完全不变，文字字号自适应原排版空间。
```

**10. 四格故事分镜。** 一句话概括故事，拆成四个有变化的瞬间，锁定角色外观与画风；成图后按顺序读一遍，不解释也能看懂才算过关。

![四格宠物漫画——猫咪在玄关等待](/showcase/aacg-play10-comic.webp)

```
创作一则四格故事漫画，主角为一只橘色斑纹猫。第一格主人出门挥手告别；第二格猫咪趴在窗台向外张望；第三格猫咪在客厅沙发上蜷缩入睡；第四格主人开门回家，猫咪端坐在玄关等待。保持角色造型统一，线条简洁温馨。
```

## 案例背后的官方指南

一条不显眼的骨架：图鉴里几乎所有标志性玩法，都能对应到 [OpenAI 官方 gpt-image-2.6 提示指南](https://developers.openai.com/api/docs/guides/image-prompting?model=gpt-image-2.6)的具名章节——生成循环 GIF、圈选引导编辑、保版式翻译、草图转写实、故事转四格漫画、保持角色一致性、生成界面预览。

所以这个图鉴可以读作官方菜谱之上的一层社区实证：官方指南说这个能力存在，图鉴告诉你谁已经把它跑通了、用的什么提示词。

## 社区怎么评价它押注的模型

为什么集中在 GPT Image 2.6？[卡尔的AI沃茨的横测](https://mp.weixin.qq.com/s/ASxig6mFVYxrIE8-8Fthew)拿它和 Nano Banana 2 在五个真实场景里对打，给出了背景：

* **文字与中文排版**——GPT 的海报像真品牌（细衬线字体、像淘宝实拍的产品页）；Banana 的「AI 感」偏重。图鉴的海报与信息图案例就长在这里。
* **界面复刻**——GPT 产出了可信的音乐播放器和电商首页；这正是图鉴 UI 原型玩法的来源。
* **真实世界摄影**——两边接近，甚至能从画面里的一辆蓝色 ofo 单车猜训练数据的年代。
* **一致性与参考编辑**——大体平手，但 GPT 的点击即编辑交互和漫画翻译时的文字稳定性更突出。

图鉴恰好站在这场对比的赢家一侧——而对比文章本身的提示词也值得一读。

## 使用时记着的几点

* **提示词不保证同款结果。** README 原话：公开提示词不保证相同输出。
* **GPT Image 2.6 优先。** 其他模型已宣布但收录很少；来源未注明模型的案例会标「模型待确认」。
* **部分演示是概念验证。** Datawhale 教程自己就提醒：动作帧序列进游戏引擎前要人工对齐，多图标画板上线前要拆成组件。
* **素材不在 MIT 范围内。** 只有代码开源；第三方图片与视频归权利人所有。
