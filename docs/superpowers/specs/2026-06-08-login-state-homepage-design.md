# 登录状态首页改造设计

## 概述

根据 `home-login.html` 的设计参考，改造首页（`/app/routes/index.tsx`），使其在已登录状态下呈现更丰富的布局，未登录状态保持现有简约设计不变。

## 状态切换规则

| 状态 | 行为 |
|------|------|
| **未登录** | 保持现有设计：AuthBar（右上角）+ 简约 Hero（码上钉）+ Paste/Drop tab + 发布按钮 + 匿名说明 |
| **已登录** | 显示全套丰富布局：TopNavBar + 增强 Hero + 丰富上传表单 + UserCenter + 统计区 + 页脚 |

状态通过 `authClient.getSession()` 判断（复用现有 `AuthBar`/`UserCenter` 的鉴权逻辑）。

## 设计详情

### 1. 顶部导航栏 (TopNavBar)

- **位置**：页面顶部，sticky 固定，左侧与 Hero 内容对齐（max-w 约束）
- **可见性**：仅已登录用户可见；未登录时隐藏，保留右上角 AuthBar
- **左侧区域**：
  - 100mini Logo（方形绿色图标 + "100mini" 文字）
  - 导航链接：首页（激活态，带下划线指示器）、我的链接
- **右侧区域**：
  - 搜索框（带搜索图标，placeholder "搜索页面..."）
  - 通知图标（铃铛 🔔）
  - 设置图标（齿轮 ⚙️）
  - 用户头像（圆形，首字母，绿色背景）
- **分隔**：底部 1px 边框线分隔导航栏与内容区

### 2. Hero 区域

- Hero 标题："一键分享你的 HTML"
- Hero 副标题："粘贴代码或上传文件，30 秒生成分享链接"
- 居中布局，与导航栏左侧对齐

### 3. 上传表单区域

在 Hero 下方居中卡片内，保持现有核心交互：

- **Tabs**：粘贴代码 / 上传文件（保持现有 `Tabs` 组件）
- **粘贴模式**：textarea（保持现有样式）
- **上传模式**：DropZone（保持现有组件）
- **文件大小指示器**：保持现有格式（xx B / 5 MB）
- **表单扩展**（较未登录新增）：
  - 标题输入（可选）
  - 类型选择器（通用/笔记/课件/工具/其他）
  - 标签输入（输入后以 chip 形式展示，可删除）
- **发布按钮**：带图标 "🚀 发布并分享"，宽度 100%

### 4. UserCenter（我的页面）

- **位置**：保持现有内联位置（上传表单下方）
- **触发方式**：页面加载后自动展示，无需点击导航"我的链接"
- 导航栏"我的链接"可滚动定位到该区域（可选增强）

### 5. 统计区 (Stats Section)

- 3 列等宽卡片，浅灰背景区分
- 左侧：⚡ 即时预览 — "粘贴即预览，高保真渲染"
- 中间：🔒 加密存储 — "内容安全加密，隐私有保障"
- 右侧：🔗 一键分享 — "生成链接或二维码，方便传播"

### 6. 页脚 (Footer)

- 上边框分隔
- 左侧：100mini（品牌色绿色）+ © 版权信息
- 右侧：隐私政策 / 服务条款 / 帮助中心 / 联系我们

## 实现约束

- **品牌**：保持 "100mini / 码上钉"，不改 StudyHub
- **功能**：继续做 HTML 代码分享（粘贴/上传 .html），不做文档分享转型
- **样式系统**：使用现有 shadcn/ui + Tailwind CSS，不引入 home-login.html 的 Material Symbols 字体
- **状态管理**：使用现有 `authClient.getSession()` 获取用户状态，不引入新的全局状态管理
- **组件复用**：优先复用现有 `AuthBar`、`UserCenter`、`DropZone`、`SuccessCard`、UI 组件

## 文件变更范围

| 文件 | 变更类型 | 说明 |
|------|----------|------|
| `app/routes/index.tsx` | 修改 | 根据登录状态条件渲染不同布局 |
| `app/components/HomeHeader.tsx` | 新增 | 提取已登录状态的导航栏组件 |
| `app/components/StatsSection.tsx` | 新增 | 提取统计区组件 |
| `app/components/AppFooter.tsx` | 新增 | 提取页脚组件 |
| 现有组件（AuthBar, UserCenter 等） | 不变 | 现有组件保持不动 |

## 实施建议

1. 先提取公共组件（HomeHeader, StatsSection, AppFooter）
2. 修改 index.tsx，加入登录状态判断逻辑
3. 已登录分支组装新布局，未登录分支保持现有代码
4. 验证状态切换流畅性（登录→刷新→登出→刷新）
